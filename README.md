# ☕ Coffee-Shop-Sales-Analysis - Dashboard

This project presents a comprehensive Coffee Shop Sales Analysis created using Microsoft Excel. The dashboard provides insights into sales trends, customer behavior, peak business hours, product category performance, and store-wise comparisons.
It is designed to help understand business performance through dynamic and interactive visuals.

📌 Project Objective

The objective of this project is to analyze coffee shop transaction data and identify key patterns that can support business decisions.
The dashboard makes it easy to:

Track total sales and total transactions

Identify peak ordering time slots

Understand product category contribution

Compare store-wise footfall and sales

Analyze weekday ordering patterns

Find top-selling products

Explore order size distribution

📊 Dashboard Features
✔ KPI Summary
Total Sales, Total Orders, Average Rating, Items Per Transaction

✔ Quantity Ordered by Hour

A line chart showing customer rush hours, with peak orders observed between 9 AM and 11 AM.

✔ Product Category Distribution

A pie chart displaying percentage contribution from categories like Coffee, Tea, Bakery, Coffee Beans, Drinking Chocolate, etc.

✔ Order Size Distribution

Breakdown of Large, Regular, Small, and Undefined order sizes.

✔ Store-wise Footfall & Sales

Comparison of sales and customer visits across:

Astoria

Hell’s Kitchen

Lower Manhattan

✔ Top 5 Products by Sales

Analysis of top-performing drinks such as:

Barista Espresso

Brewed Black Tea

Brewed Chai Tea

Gourmet Brewed Coffee

Hot Chocolate

✔ Orders by Weekday

Shows demand variations across weekdays, with Friday having the highest number of orders.
